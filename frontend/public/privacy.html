Privasi lokasi

AntarFix Estimator · diperbarui 18 September 2026

Data yang digunakan

Aplikasi menggunakan titik jemput, titik tujuan, dan lokasi perangkat jika Anda memberikan izin. Izin lokasi dapat ditolak; titik tetap bisa dipilih secara manual.

Tujuan penggunaan

Koordinat digunakan untuk mencari nama tempat, menghitung rute jalan, jarak, waktu, dan estimasi biaya. Data tersebut tidak digunakan untuk membuat akun atau melacak perjalanan setelah halaman ditutup.

Layanan pendukung

  • OpenStreetMap menyediakan data peta dan nama tempat.
  • Nominatim membantu pencarian serta penerjemahan koordinat menjadi alamat.
  • OSRM menghitung rute, jarak, dan perkiraan waktu tempuh.

Permintaan ke layanan tersebut dapat menyertakan koordinat dan informasi teknis koneksi seperti alamat IP.

Penyimpanan

AntarFix Estimator saat ini tidak memiliki akun pengguna atau database lokasi. Hasil pencarian alamat dapat disimpan sementara di memori server untuk mempercepat permintaan berikutnya dan akan hilang ketika proses server dimulai ulang.

Kendali Anda

Anda dapat mencabut izin lokasi melalui pengaturan browser, memilih titik secara manual, atau menutup halaman tanpa melakukan estimasi. Untuk pertanyaan lebih lanjut, gunakan kanal resmi AntarFix.
